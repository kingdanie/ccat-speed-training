# CCAT Speed Training

A self-contained training app for the Criteria Cognitive Aptitude Test (CCAT), the 50-question / 15-minute screen used in Crossover's hiring process.

No build step, no dependencies and no network calls. Open `index.html` in a browser and it runs.

## Why it exists

The CCAT gives you about 18 seconds per question and almost nobody finishes. Passing is a pacing problem, not a knowledge problem, so this app drills technique against a stopwatch rather than teaching content.

## What's in it

**Stage 1 — Pacing**
How the test is scored, and the triage rule: five seconds to find a path, a 25-second ceiling, guess and never return.

**Stage 2 — Seven technique modules**

| Module | Teaches |
|---|---|
| Number series | Checking differences → second differences → ratios → alternation, in that fixed order |
| Math & word problems | Percentage shortcuts, reverse percentages, rates, inverse work problems, ratios |
| Verbal reasoning | The sentence method for analogies, tone-flipping for antonyms, category-finding for odd-one-out |
| Logic & deduction | Two-circle syllogism diagrams, the contrapositive rule, ordering chains |
| Spatial reasoning | The five-attribute checklist: rotation, shading, count, position, reflection |
| Attention to detail | Chunked comparison, and where differences get planted |
| Exam-style mixed set | Real question wording with nothing signalling which technique applies |

Each module gives the method, two worked examples showing where the seconds go, then a timed drill. Every question returns the reasoning and a speed tip the moment you answer.

**Stage 3 — Question bank and simulation**

A bank of 700+ questions covering all fourteen CCAT question types, filterable by category and type. Pick a type, drill 20 or 50 of it against the clock. The full simulation draws 50 from the bank in the test's own proportions (17 math and logic, 17 verbal, 16 spatial) and reports accuracy and average time per question type, so you know exactly what to work on next.

78 taught questions in the modules, plus the generated bank.

## The question bank

The bank isn't scraped from prep sites — those are commercial products, and the real CCAT items are private to Criteria Corp. It's generated by `scripts/generate-bank.js`, which builds original questions from the archetypes the test actually uses:

| Category | Types |
|---|---|
| Math & logic | Number series, basic arithmetic, word problems, tables & graphs |
| Verbal | Analogies, antonyms, synonyms, sentence completion, attention to detail, syllogisms, ordering |
| Spatial | Shape series, matrix patterns, odd one out |

Two design rules make it trustworthy:

**Answers are computed, never typed.** The same code that builds a question derives its answer, so the two cannot drift apart. Distractors are generated as near-misses modelling the specific mistake a rushed candidate makes — dividing by the new value instead of the old one, adding successive percentages instead of compounding them.

**Everything is re-checked independently.** `scripts/validate-bank.js` re-solves every question it can with logic that shares no code with the generator, and fails if the two disagree. It currently re-solves 477 of 701 (68%); the rest are vocabulary items whose answers come from curated word lists rather than computation. It also checks for duplicate options, malformed items, and drift from the test's category balance.

Regenerating gives a fresh set, which is the point — you train the method rather than memorising items. That matters because Crossover makes you retake the CCAT under webcam proctoring after the offer.

```bash
node scripts/generate-bank.js    # rebuild bank.js
node scripts/validate-bank.js    # verify it
```

Spatial questions store a compact figure spec rather than SVG markup; the page renders them at runtime, which keeps the file small and the shapes crisp at any size.

## The stopwatch

Every drill question is timed and colour-coded against the real budget:

- **Blue** — under 18 seconds, on pace
- **Amber** — 18 to 25 seconds, over the average
- **Red** — past 25 seconds, where tests are lost

## Progress tracking

Results are held in memory for the session and shown in the progress view, which marks each module Fast, Slow or Needs work based on accuracy and average time. Refreshing clears them — finish a drill before leaving the page.

## Running it

Open `index.html`. That's the whole setup.

To reach it from a phone, enable GitHub Pages on this repo (Settings → Pages → deploy from the default branch, root folder) and it will serve at the Pages URL.

## Suggested schedule

- **Days 1–3** — one module per day, read then drill. Reread the technique for anything under 70% accuracy.
- **Days 4–12** — one simulation daily, then redo the drills for your two weakest categories.
- **Final three days** — two simulations a day. Stop learning new methods; rehearse the triage rule until it's automatic.

## A note on the questions

Every question is original, written or generated to match the CCAT's archetypes. None are retrieved test items, and none are copied from prep vendors. The test format was checked against Criteria Corp's own candidate documentation: 50 questions, 15 minutes, three roughly equal categories.
